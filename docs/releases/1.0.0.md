# Prism Dashboard 1.0.0

The first public Prism release brings music, a calendar, and weather into one
Omarchy panel.

- Album artwork sets the player and clock colors together.
- Drifting dots, soft waves, and a liquid hover trail give the cover motion.
- CAVA draws an audio spectrum behind the clock; right-click cycles formats.
- Spotify gets confirmed, add-only Liked Songs. Podcasts get timed skips,
  and browser media links back to its page.
- City search confirms region, country, and coordinates. Open-Meteo provides
  current weather and the upcoming hours in Celsius or Fahrenheit.
- Simple settings control each visual effect and save immediately.

## Install

```bash
omarchy plugin add https://github.com/sadraalikhah/prism-dashboard.git
omarchy plugin enable io.github.sadraalikhah.prism-dashboard --section center
```

This release has its own ID and does not replace another plugin automatically.
The setup guide explains how to move existing clock preferences to Prism.
CAVA and the Spicetify integration are optional. See the README for requirements.

The feature guide includes screenshots and nine silent recordings with
Poison Girl by HIM and Paris demo weather. Credits distinguish source and
third-party media licenses and explain the isolated demo fixtures.

Validation covers artwork colors, weather parsing, provider actions,
confirmed Spotify saves, the local bridge, and the actual QML controls and
new-ID preference persistence. The Omarchy manifest validates.
